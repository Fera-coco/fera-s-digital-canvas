# Superb Naturals demo (two versions)

- Version A "Bloom" (colourful): `npm run build` → copy `dist` to `public/demos/superb-naturals`
- Version B "Classic" (clean, in the style of the site the client likes): `VITE_THEME=classic npx vite build` → copy `dist-classic` to `public/demos/superb-naturals-classic`

Prices come from the client's WhatsApp catalogue (22 Nov 2026). Bank details are placeholders.
